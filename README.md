# 🚀 TaskFlow Pro — AI-Powered Development & Productivity Platform

TaskFlow Pro is a full-stack web application designed to bring coding, workspace management, and AI-powered assistance together in one platform. It provides users with secure authentication and a browser-based coding workspace.

## 🌐 Live Demo

**Live Application:** https://taskflow-pro-kri7.onrender.com/

**GitHub Repository:** https://github.com/rudrakotasuchi-maker/TaskFlow-Pro

> Note: The application is hosted on Render, so the first request after a period of inactivity may take some time to load.

## ✨ Features

- 🔐 **User Authentication:** Registration and login with Spring Security.
- 💻 **Online Code Editor:** Browser-based coding workspace powered by Monaco Editor.
- 📁 **Workspace Management:** Organize and manage coding workspace files.
- 🤖 **AI Integration:** Gemini API integration for AI-powered assistance.
- 🗄️ **Database Integration:** Persistent data storage using MySQL and Spring Data JPA.
- ☁️ **Cloud Deployment:** Spring Boot application deployed on Render with a cloud-hosted MySQL database.

## 🛠️ Tech Stack

**Backend:** Java 17, Spring Boot, Spring Security, Spring MVC, REST APIs

**Frontend:** HTML, CSS, JavaScript, Thymeleaf, Bootstrap, Monaco Editor

**Database:** MySQL, Hibernate, Spring Data JPA

**AI:** Google Gemini API

**Tools & Deployment:** Maven, Git, GitHub, Docker, Render, Aiven
